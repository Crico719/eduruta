# 🌱 EduRuta

App educativa estilo Duolingo para estudiantes de **1° y 2° de secundaria (Perú)**.
Aprende Matemática a tu propio ritmo con lecciones cortas, puntos, rachas y medallas.

## ✨ Características

- 📘 **6 unidades** de Matemática de 1° de secundaria (currículo MINEDU)
- 🎯 **12 lecciones** con explicación + preguntas de práctica
- ❤️ **Sistema de corazones** (3 vidas por lección)
- ⭐ **XP y niveles** — sube de nivel mientras aprendes
- 🔥 **Rachas diarias** — estudia todos los días
- 💾 **Progreso guardado** automáticamente en tu navegador (localStorage)
- 🎉 **Confeti y celebraciones** al completar lecciones
- 📱 **Diseño responsivo** — funciona en celular y computadora

## 📚 Contenido incluido (1° Secundaria)

| Unidad | Temas |
|--------|-------|
| 1 | Números enteros — concepto y operaciones |
| 2 | Fracciones — equivalentes, suma y resta |
| 3 | Números decimales — lectura y operaciones |
| 4 | Expresiones algebraicas — variables y valor numérico |
| 5 | Ecuaciones de primer grado — resolución y problemas |
| 6 | Geometría — perímetro y área |

> Próximamente: Ciencia y Tecnología, Comunicación, Ciencias Sociales y 2° de secundaria.

## 🚀 Cómo usarla

1. Descarga `eduruta.html`
2. Ábrelo con cualquier navegador (doble clic)
3. ¡Empieza a aprender! No necesita instalación ni internet.

## 🌐 Publicar en GitHub Pages

1. Crea un repositorio en GitHub (ej: `eduruta`)
2. Sube el archivo `eduruta.html` como `index.html`
3. Ve a **Settings → Pages**
4. En "Source" elige la rama `main` y carpeta `/ (root)`
5. Tu app estará en: `https://TU-USUARIO.github.io/eduruta/`

## 🛠️ Tecnologías

- HTML5 + CSS3 + JavaScript (vanilla)
- Sin dependencias externas — un solo archivo
- localStorage para guardar el progreso
